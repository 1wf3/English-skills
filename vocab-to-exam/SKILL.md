# 单词变考题

把孤立词表转成自然、连贯、有可验证答案的考试风格练习。说明与解析用中文；英语阅读材料、题干和选项用英文。生成的是原创模拟练习，不能标为真题或声称经过官方难度标定。

## 接收与默认值

从消息、附件或当前对话提取：词表、四级/六级/考研英语一/英语二、题型、篇数/题量、主题、篇幅、难度、词汇覆盖要求、答案展示方式。直接接受逗号、换行、词组、带音标或中文释义的词表，不要求填写表格。

- 用户给了词表即可开始。沿用当前对话中已明确的偏好，用户本次要求优先。
- 没有可读取的词表时，只问用户发送词表；不要虚构“用户背过的词”。图片无法辨认的条目单独列出，清晰条目可先使用。
- 没指定考试或题型：默认“四级仔细阅读，1篇、5道四选一”，用一句话告知后直接生成。只说“考研”时默认英语一并说明，允许随时改为英语二。
- 同时指定多个题型：按指定范围分别生成，不自动扩展为整套试卷。明确要求“整套阅读”时遵循参考文件里的完整题量。
- 默认练习模式：先只给试题。用户要求“附答案/带解析/自学版”则把答案解析集中在试题之后；“考试模式/不要答案”时，连词汇释义、全文翻译和覆盖明细也留到交卷后。
- 用户自定篇幅、难度、方向或题量优先；偏离常规考试形式时简短标为“专项/缩短版练习”。不要把六级文章简单替换几个难词当作考研阅读。

生成指定题型前，读取 [references/exam-formats.md](references/exam-formats.md) 中对应部分。普通原创训练无需每次联网；要求特定年份最新大纲、真题或精确官方标准时，核验官方来源并标明年份，不把参考文件中的历史资料当作最新大纲。

## 考纲对齐边界

- 默认按对应考试的题型与能力要求编原创模拟题；用户要求“严格按考纲”时，先明确使用的大纲版本，区分已核验的条款与尚未核验的词表/版本，不承诺官方等值难度。
- 词汇覆盖率与考纲词汇合规是两回事。有可核验的对应版本词表时，对目标词及新增难词检查基本词形、屈折变化和附表，记录疑似超纲或未确认词；没有可靠词表时只做难度控制，不能声称“全部考纲内”或报精确超纲比例。
- 用户词表与考试题材、篇幅、词汇要求冲突时，优先保持模拟题格式和自然语篇，暂缓不适合的目标词并在作答后说明；用户明确优先全覆盖时可做词汇专项并标出偏离项。
- 四六级超纲且影响理解或答题的词，按大纲要求可在题面给必要中文注释；这是默认不展示词汇释义的例外。考研模拟题不默认加中文词注，控制额外生词，学习版按用户要求提供辅助。
- 考纲对真实四六级客观题语料有英文原版选材要求；本技能默认原创文章，只能称“按考纲题型和能力要求设计的原创模拟题”。用户要原版选材时另找可核实出处的合适材料并依法引用或改编，标清来源与改编，不能将原创伪装为原版。
- 发布前检查篇幅、题量、选项、翻译方向与所选格式；严格篇幅要求时实际统计英文词数/汉字数。单篇训练和整板块模拟分别命名，不把缩减题标成完整板块。

## 词表与覆盖

1. 去重并保留原词与用户给定词义。词形明显拼错时列出简短更正；有多种合理解释则保留不确定项，不悄悄替换。多词短语作为一个目标项。
2. 优先围绕能自然共现的词选题，再写有中心、有推进的文章。词义、词性、搭配及语体必须正确；用户指定的词义优先，不为了塞词扭曲意思。
3. 默认尽可能覆盖全部词表。词多或主题跨度大时按主题分组；用户只要1篇时守住篇数和自然度，剩余词明确列为未覆盖，不强塞或私自增加多篇。用户要求全部覆盖又限定很短时，说明冲突并让用户选择扩篇或放宽覆盖。
4. 原词与正常屈折形式（如 decide/decided）可计入覆盖；派生词（decide/decision）不能冒充原词。短语须整体或以自然允许的变体出现。用户要求原形时遵守原形要求。
5. 阅读的覆盖只统计正文，不能靠题目、选项或词汇表凑数。选词填空按完整填回后的正文统计，同时区分词库干扰项。汉译英按参考译文统计，标明“参考译文覆盖”，不声称中文题面出现了英语词。
6. 输出覆盖明细时，用“原词｜实际形式｜语境义｜位置”列出；未覆盖单列。覆盖率为正文实际覆盖的目标项数/去重后的有效目标项数，存在未确认词时注明不纳入分母。未逐项核查，不报100%。

默认正文不加粗目标词、不附逐词释义，保护做题体验。用户要“学习版/标出生词”时可加粗，词汇表和全文译文仍默认放在答案区。

## 编题与内部核查

- 先写完整材料，再根据实际材料出题。主题可为校园、科技、社会、文化、教育、环境或经济；无需专业背景才能答题。虚构人物、调查及数据作为模拟情境，不伪称真实研究或杜撰引用。
- 选择题每题只有一个最优答案。细节、推断、主旨、态度、语义题按文章适当组合，不强求每篇机械凑全；考研训练还须涵盖文章结构、论证方法/修辞和观点比较等能力，不能把英语二固定成简单细节定位题。推断不能依赖文章外常识。
- 干扰项应有可信来源，例如范围扩大、因果颠倒、对象偷换或文中未提及；避免明显荒谬选项、长度泄题及正确项连续机械排列。
- 段落匹配需依靠信息与同义改写作答，逐题检查是否仅有一个足够明确的段落；题面写清段落可否重复使用。考研新题型按对应规则生成，不能拿四六级10题匹配直接冒充。
- 选词填空逐空检查词性、时态、搭配和全篇语义，排除另一个词同样成立的情况；词库数、空数及答案使用次数符合所选格式。
- 翻译材料须能自然表达目标词的意思。汉译英通常存在多个合格译法，参考译文不是唯一答案；若用户要求必须使用指定词，题面明确该约束。考研英语一须给完整上下文并清晰标出待译的5处。
- 发布前对照正文逐题作答，核查答案、定位与解析一致，修改歧义题。无需向用户展示内部推理过程，只给必要证据与讲解。

## 交付与批改

试题开头简短列出考试、题型、篇数/题数、模拟练习标识和建议用时（用时是训练建议）。正文段落用稳定编号如[P1]、[P2]；匹配题按[A]、[B]编号。英文词数如未实际统计则写“约”，不要伪报精确数字。

练习模式到试题结束，提示可按“1A 2C …”提交；不顺带泄露答案、词义或译文。保留当前对话中的题目与答案对应关系；跨对话拿不到原题时请用户提供原题，不猜测旧答案。

交卷或要求答案后，提供：

1. 答案与客观题得分：正确数/已作答数，并注明漏答；用户只交部分时只解析已交部分，除非要求全解。
2. 每题定位段落、必要的短原文证据、同义替换和正确理由；错误选项简明解释问题所在。不要只给答案字母。
3. 翻译给参考译文、关键表达与句法拆解；批改用户译文时区分意义错误和可接受变体，评分注明自拟练习标准。
4. 词汇覆盖明细与未覆盖词；按需选取2–3个真正影响理解的长难句讲解。全文译文仅在用户要求时提供，翻译题本身的答案除外。
5. 根据实际错题指出待复习词或定位/推断问题。用户请求二刷时，用薄弱词换语境出新题，避免重复同一答案。

不主动创建复习定时任务或声称记住跨会话学习记录。用户只要聊天练习就直接在聊天交付；要求保存、打印或导出时才创建相应文件，并遵循当前项目目录约定。
